## Results journal (append records)

Record each material result or decision, starting with intake. Keep stable IDs; correct with a linked superseding record. Distinguish hypothesis, user report, synthetic test and verified observation. Confidence is high / medium / low / unknown **with a basis and limits**, never an invented probability. Record the actual performer and source; a proposed owner is not an author. A failed attempt is a result worth preserving.

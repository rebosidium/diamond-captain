# Discover ↗ · Problem

Understand needs, contexts and competing causes before committing to a problem. Ask: what actually happens, for whom, and which explanation could change the decision? Start with credible existing evidence; select a method only for a consequential gap.

| Question or gap | Candidate | Prefer when… |
| --- | --- | --- |
| Why did someone act that way? | [QL-01 Actual-event interview](qualitative.md#ql-01) | A recent concrete episode can be reconstructed; intentions alone are insufficient. |
| What gets missed in an account? | [QL-02 Contextual observation](qualitative.md#ql-02) | Work involves interruptions, physical context or informal handoffs. |
| What happens between encounters? | [QL-04 Diary study](qualitative.md#ql-04) | Experiences are intermittent or spread across days and places. |
| What already goes wrong? | [QL-17 Support-case analysis](qualitative.md#ql-17) | Existing cases contain attempted remedies and unresolved outcomes. |
| Can these metrics be trusted? | [QT-01 Instrumentation audit](quantitative.md#qt-01) | Event meanings, identities or coverage are uncertain. |
| Where is a known journey losing people? | [QT-03 Funnel analysis](quantitative.md#qt-03) | Ordered steps and a defensible completion window exist. |
| Which routes actually occur? | [QT-04 Event-path analysis](quantitative.md#qt-04) | The journey is not known in advance and ordered events are usable. |
| Who has a different experience? | [QT-05 Segment comparison](quantitative.md#qt-05) | An aggregate may conceal role or context differences. |
| What do scattered findings suggest? | [DS-01 Evidence clustering](design-and-delivery.md#ds-01) | Existing sources need synthesis with contradictions retained. |
| Where does the whole experience break? | [DS-04 Journey synthesis](design-and-delivery.md#ds-04) | Source-linked episodes span channels, waiting and repeated attempts. |
| Who or what constrains the work? | [DS-06 Dependency map](design-and-delivery.md#ds-06) | Policies, teams or suppliers shape available options. |
| Which unknown deserves attention first? | [DS-07 Assumption risk map](design-and-delivery.md#ds-07) | Several explanations compete and the next check needs prioritising. |

Use selected cards for procedure and limits. A small useful handoff names candidate problems, evidence, alternative explanations and decision-critical gaps. Diaries and interviews do not establish prevalence; event losses do not explain motive. Without collection authority, prepare the protocol or analyse permitted sources and mark the gap honestly.

# Deploy ↗ · Outcome

Observe the exposed change in varied real contexts. Ask: who actually encountered it, what happens over time, and which harm or surprise needs action? Preparation can be useful before launch, but it is not live evidence.

| Question or gap | Candidate | Prefer when… |
| --- | --- | --- |
| What occurs outside scheduled sessions? | [QL-04 Diary study](qualitative.md#ql-04) | Real experiences recur across days, locations or infrequent events. |
| How did use change actual work? | [QL-09 Field follow-up](qualitative.md#ql-09) | Exposed users can show adaptations and unintended effects. |
| Which breakdowns reach support? | [QL-17 Support-case analysis](qualitative.md#ql-17) | Existing cases reveal failures, remedies and unresolved outcomes. |
| How do people coordinate in use? | [QL-20 Collaborative-use study](qualitative.md#ql-20) | Shared tasks depend on negotiation or control handovers. |
| Do people return meaningfully? | [QT-06 Cohort retention](quantitative.md#qt-06) | Entry and meaningful return can be tracked with adequate follow-up. |
| Where is real work accumulating? | [QT-08 Queue/service-time analysis](quantitative.md#qt-08) | Arrivals, completions, waiting and backlog are available. |
| How does experience change within a person? | [QT-13 Pulse panel](quantitative.md#qt-13) | Repeated measures are justified and attrition can be examined. |
| Is a guardrail deteriorating? | [QT-18 Process monitoring](quantitative.md#qt-18) | A stable baseline and suitable signal rules support ongoing checks. |
| Who can resolve a live dependency? | [DS-06 Dependency map](design-and-delivery.md#ds-06) | An observed handoff or supplier constraint lacks confirmed ownership. |
| Can a newly found failure be reproduced? | [DS-17 Operational rehearsal](design-and-delivery.md#ds-17) | A safe reproduction can inform a fix; simulation stays separately labelled. |
| Should exposure expand or pause? | [DS-18 Rollout/rollback plan](design-and-delivery.md#ds-18) | Actual release authority can act on verified checks and thresholds. |
| Which signals need attention now? | [DS-19 Live evidence triage](design-and-delivery.md#ds-19) | Usage, operations, support or incidents point in different directions. |

Keep exposure/version, observation window, coverage, anomalies and action owners in the checkpoint. Escalate actual harm using the applicable process; do not wait for a research cadence. Missing signals are not success, and return behaviour is not necessarily user benefit. Without verified exposure/access, retain `AWAITING LIVE EVIDENCE` for outcome claims and complete only permitted preparation.

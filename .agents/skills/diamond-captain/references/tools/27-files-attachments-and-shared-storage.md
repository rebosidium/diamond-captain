# 27. Files, attachments and shared storage

Find source material and keep artifacts retrievable. Record the actual file/revision; a shared link is not proof of access, consent or permission to upload or widen sharing.

| Candidate | When to consider it | Route to check |
| --- | --- | --- |
| [Google Drive](https://workspace.google.com/products/drive/) | Shared research material and linked document sources | B / A? / F |
| [OneDrive](https://www.microsoft.com/en-us/microsoft-365/onedrive/online-cloud-storage) | Personal or team files in Microsoft 365 | B / A? / F |
| [SharePoint](https://www.microsoft.com/en-us/microsoft-365/sharepoint/collaboration) | Team libraries, policies and controlled document homes | B / A? / F |
| [Dropbox](https://www.dropbox.com/) | Existing shared artifact and attachment folders | B / A? / F |
| [Box](https://www.box.com/) | Existing document collections and managed sharing | B / A? / F |
| [Nextcloud](https://nextcloud.com/files/) | Organization-controlled file collaboration | B / A? / F |
| [ownCloud](https://owncloud.com/) | Existing controlled file workspace | B / F |
| [Egnyte](https://www.egnyte.com/) | Team files already governed in Egnyte | B / A? / F |
| [Proton Drive](https://proton.me/drive) | Existing private file-sharing workflow | B / F |
| [Local files / MCP Filesystem](https://github.com/modelcontextprotocol/servers/tree/main/src/filesystem) | Supplied local artifacts with access limited to intended folders | L / F |

Use the [shared routing, capability limits and permissions](../tool-options.md#read-only-what-the-next-decision-needs) before acting.

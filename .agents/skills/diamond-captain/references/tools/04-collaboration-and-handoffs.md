# 4. Collaboration and handoffs

Choose when the task needs existing discussion context or a human review. Reading a channel does not authorize sending a message.

| Candidate | When to consider it | Route to check |
| --- | --- | --- |
| [Slack](https://slack.com/) | Search existing team discussions and decisions | B / A? |
| [Microsoft Teams](https://www.microsoft.com/microsoft-teams/group-chat-software) | Existing Microsoft workplace conversations and meetings | B |
| [Discord](https://discord.com/) | Community or team feedback already collected there | B |
| [Zoom](https://www.zoom.com/) | Remote stakeholder reviews or research calls | B |
| [Google Meet](https://workspace.google.com/products/meet/) | Remote reviews in a Google Workspace team | B |
| [Loom](https://www.loom.com/) | Asynchronous walkthroughs and contextual handoff recordings | B |
| [Mattermost](https://mattermost.com/) | Team collaboration with deployment-control requirements | B |
| [Rocket.Chat](https://www.rocket.chat/) | Existing controlled or federated communication workspace | B |
| [Zulip](https://zulip.com/) | Topic-based discussions with retrievable decision context | B / A? |
| [Basecamp](https://basecamp.com/) | Project discussions, handoffs and team coordination | B |

Use the [shared routing, capability limits and permissions](../tool-options.md#read-only-what-the-next-decision-needs) before acting.

# 24. Spreadsheets, statistics and data-quality analysis

Choose when supplied data needs cleaning, denominator checks, uncertainty estimates or reproducible calculations. Inspect grain, missingness, duplicates and sampling; statistical software does not rescue an unsuitable study design.

| Candidate | When to consider it | Route to check |
| --- | --- | --- |
| [Microsoft Excel](https://www.microsoft.com/en-us/microsoft-365/excel) | Inspect and share existing spreadsheet calculations | B / F |
| [Google Sheets](https://workspace.google.com/products/sheets/) | Collaborative small-data review in an existing workspace | B / F |
| [LibreOffice Calc](https://www.libreoffice.org/) | Local spreadsheet analysis with compatible file formats | L / F |
| [Jupyter](https://jupyter.org/) | Reproducible notebook with data, calculations and explanation | L / F |
| [pandas](https://pandas.pydata.org/) | Programmatic cleaning and analysis of structured files | L / F |
| [RStudio](https://posit.co/products/open-source/rstudio) | Statistical analysis in an existing R environment | L / F |
| [DuckDB](https://duckdb.org/) | Query local analytical files with SQL | L / F |
| [OpenRefine](https://openrefine.org/) | Inspect and clean inconsistent tabular values | L / F |
| [jamovi](https://www.jamovi.org/) | GUI-based statistical analysis with inspectable results | B / L / F |
| [JASP](https://jasp-stats.org/) | GUI-based frequentist or Bayesian statistical analysis | L / F |

Use the [shared routing, capability limits and permissions](../tool-options.md#read-only-what-the-next-decision-needs) before acting.

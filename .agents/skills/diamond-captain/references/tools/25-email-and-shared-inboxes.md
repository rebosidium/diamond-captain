# 25. Email and shared inboxes

Read supplied or authorized message threads for requests, constraints, feedback and handoffs. Drafting a reply is distinct from sending it.

| Candidate | When to consider it | Route to check |
| --- | --- | --- |
| [Gmail](https://workspace.google.com/products/gmail/) | Work already coordinated through Google mail | B / A? |
| [Outlook](https://www.microsoft.com/en-us/microsoft-365/outlook/email-and-calendar-software-microsoft-outlook) | Mail and attachments in a Microsoft workplace | B / A? |
| [Fastmail](https://www.fastmail.com/) | An existing Fastmail inbox is the evidence source | B |
| [Proton Mail](https://proton.me/mail) | Existing mail with constrained sharing or export | B / F |
| [Front](https://front.com/) | Shared customer inbox and team follow-through | B / A? |
| [Missive](https://missiveapp.com/) | Shared inbox conversations and accountable replies | B / A? |
| [Superhuman Mail](https://superhuman.com/mail) | The team already uses this mail client | B |
| [Shortwave](https://www.shortwave.com/) | Existing team mail triage and conversation context | B |
| [Thunderbird](https://www.thunderbird.net/) | Local mail review and compatible exported messages | B / F |
| [Apple Mail](https://support.apple.com/guide/mail/welcome/mac) | Authorized macOS mail review in an existing account | B / F |

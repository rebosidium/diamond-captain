# 2. Product planning and task tracking

Choose when decisions need owners, scope, sequencing or follow-through. Reuse the existing tracker.

**Atlassian is broader than Jira.** The [Atlassian platform / Rovo MCP](https://developer.atlassian.com/cloud/rovo-mcp/) can provide cross-app routes for Jira, Confluence, Loom and connected work. Inspect the host's actual operations and [current supported tools](https://developer.atlassian.com/cloud/rovo-mcp/guides/supported-tools/); a Jira issue search is not a search of every Atlassian source. Use Confluence for documents, Loom for recordings, and the relevant tracker for delivery records when available and authorized.

| Candidate | When to consider it | Route to check |
| --- | --- | --- |
| [Jira](https://www.atlassian.com/software/jira) | Delivery work already coordinated in Atlassian | B / A? |
| [Linear](https://linear.app/) | Product/engineering issues, projects and cycles | B / A? |
| [Trello](https://trello.com/) | Small teams needing a simple visual board | B / A? |
| [Asana](https://asana.com/) | Cross-functional tasks, dependencies and accountable owners | B / A? |
| [monday.com](https://monday.com/) | Configurable operational and project workflows | B |
| [ClickUp](https://clickup.com/) | Tasks, documents and delivery in one workspace | B |
| [Productboard](https://www.productboard.com/) | Connect customer signals with prioritization decisions | B |
| [Aha!](https://www.aha.io/) | Strategy, roadmaps and portfolio-level product planning | B |
| [GitHub Issues / Projects](https://github.com/features/issues) | Keep delivery decisions beside implementation work | B / A? |
| [Plane](https://plane.so/) | Issue/project planning with a self-hosting option | B |

Use the [shared routing, capability limits and permissions](../tool-options.md#read-only-what-the-next-decision-needs) before acting.

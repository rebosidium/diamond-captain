# 7. Quantitative product and web analytics

Choose when event, funnel, cohort or traffic evidence can answer a defined question. Check instrumentation, denominators, population, consent and data quality before interpretation; no counter is universally privacy-compliant.

| Candidate | When to consider it | Route to check |
| --- | --- | --- |
| [PostHog](https://posthog.com/) | Product funnels, retention and behavior with linked evidence | B / A? |
| [Amplitude](https://amplitude.com/) | Product usage, cohorts and lifecycle questions | B / A? |
| [Mixpanel](https://mixpanel.com/) | Event-based funnels and retention analysis | B / A? |
| [Google Analytics](https://marketingplatform.google.com/about/analytics/) | Existing acquisition, web and conversion measurement | B / A? |
| [Matomo](https://matomo.org/) | Web analytics where data/deployment control matters | B / A? |
| [Plausible](https://plausible.io/) | Lightweight site traffic and goal measurement | B / A? |
| [Piwik PRO](https://piwik.pro/) | Existing enterprise analytics and consent-management stack | B |
| [Heap](https://www.heap.io/) | Explore captured behavioral data and conversion paths | B |
| [Fullstory](https://www.fullstory.com/) | Relate behavioral analytics to recorded experience context | B |
| [Adobe Analytics](https://business.adobe.com/products/adobe-analytics.html) | Existing enterprise digital analytics environment | B |

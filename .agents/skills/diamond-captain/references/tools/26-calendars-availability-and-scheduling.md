# 26. Calendars, availability and scheduling

Coordinate research, workshops, review windows and follow-up owners. Available slots are not booked participants; calendar access does not authorize invitations.

| Candidate | When to consider it | Route to check |
| --- | --- | --- |
| [Google Calendar](https://workspace.google.com/products/calendar/) | Team availability and dated review triggers | B / A? |
| [Outlook Calendar](https://www.microsoft.com/en-us/microsoft-365/outlook/calendar-app) | Availability in a Microsoft workplace | B / A? |
| [Apple Calendar](https://support.apple.com/guide/calendar/welcome/mac) | Existing macOS calendar and compatible event files | B / F |
| [Calendly](https://calendly.com/) | An existing participant or stakeholder booking flow | B / A? |
| [Cal.com](https://cal.com/) | Existing scheduling workflow with controlled deployment | B / A? |
| [SavvyCal](https://savvycal.com/) | Existing cross-team scheduling links | B |
| [Doodle](https://doodle.com/) | Agree a group review or workshop time | B |
| [YouCanBookMe](https://youcanbook.me/) | An existing appointment booking page | B |
| [Acuity Scheduling](https://acuityscheduling.com/) | Service appointments and operational scheduling context | B |
| [Zoho Bookings](https://www.zoho.com/bookings/) | Scheduling already managed in a Zoho workspace | B / A? |

Use the [shared routing, capability limits and permissions](../tool-options.md#read-only-what-the-next-decision-needs) before acting.

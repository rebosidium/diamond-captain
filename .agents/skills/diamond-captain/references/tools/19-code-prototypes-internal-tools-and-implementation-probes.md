# 19. Code prototypes, internal tools and implementation probes

Choose when a working behavior, feasibility probe or operational tool answers the next question. Frameworks require an appropriate installed runtime; use the current project stack and avoid migrating it for this menu.

| Candidate | When to consider it | Route to check |
| --- | --- | --- |
| [Vite](https://vite.dev/) | Fast local web prototype using the team's framework | L / F |
| [React](https://react.dev/) | Reusable interactive UI in an existing React project | L / F |
| [Next.js](https://nextjs.org/) | Web flows requiring an existing full-stack React environment | L / F |
| [Astro](https://astro.build/) | Content-heavy web prototypes with limited interaction | L / F |
| [Svelte / SvelteKit](https://svelte.dev/) | Interactive prototypes in an existing Svelte environment | L / F |
| [Streamlit](https://streamlit.io/) | Data-oriented prototype or internal analytical workflow | L / F |
| [Gradio](https://gradio.app/) | Testable model/input/output interface for an AI concept | L / F |
| [Retool](https://retool.com/) | Internal operational interface on authorized data | B |
| [Appsmith](https://www.appsmith.com/) | Internal tools in an existing low-code environment | B |
| [Budibase](https://budibase.com/) | Internal apps, forms and operational workflows | B |

Use the [shared routing, capability limits and permissions](../tool-options.md#read-only-what-the-next-decision-needs) before acting.

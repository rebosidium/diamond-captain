# 29. Forms, approvals and sign-off records

Collect structured requests or preserve a real review decision. Form submission, a signature request and accepted design DoD are different events; record the actual owner, response and scope.

| Candidate | When to consider it | Route to check |
| --- | --- | --- |
| [Google Forms](https://workspace.google.com/products/forms/) | Structured intake in Google Workspace | B / F |

| [Typeform](https://www.typeform.com/) | An existing intake or feedback form | B / A? / F |
| [Tally](https://tally.so/) | A lightweight existing request form | B / F |
| [Jotform](https://www.jotform.com/) | Existing forms and operational intake | B / A? / F |

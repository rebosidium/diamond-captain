# 5. Qualitative research repository and synthesis

Choose when real observations need coding, comparison, traceability or reuse. AI summaries and simulated personas do not replace participant evidence; retain source passages and distinguish interpretation.

| Candidate | When to consider it | Route to check |
| --- | --- | --- |
| [Dovetail](https://dovetail.com/) | Search and synthesize a shared customer-evidence repository | B / A? |
| [Condens](https://condens.io/) | Code observations and connect findings to research | B |
| [Marvin](https://heymarvin.com/) | Centralize interview knowledge and customer insights | B |
| [Aurelius](https://www.aureliuslab.com/) | Organize research evidence, themes and usable insights | B |
| [Looppanel](https://www.looppanel.com/) | Analyze interview recordings and retrieve research findings | B |
| [NVivo](https://lumivero.com/products/nvivo/) | Structured qualitative coding and mixed-source analysis | B / F |
| [ATLAS.ti](https://atlasti.com/) | Qualitative analysis across interview and document data | B / F |
| [MAXQDA](https://www.maxqda.com/) | Qualitative or mixed-method analysis with explicit coding | B / F |
| [Notion](https://www.notion.com/) | Small study needing a manual evidence index | B / A? |
| [Airtable](https://www.airtable.com/) | Structured observations with participant/source fields | B / A? |

Use the [shared routing, capability limits and permissions](../tool-options.md#read-only-what-the-next-decision-needs) before acting.

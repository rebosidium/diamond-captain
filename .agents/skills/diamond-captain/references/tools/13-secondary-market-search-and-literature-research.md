# 13. Secondary, market, search and literature research

Choose when external evidence can inform framing, demand, discoverability or prior knowledge. Search snippets are leads; inspect primary sources. Vendor traffic estimates are estimates, and publication metadata is not full-text evidence.

| Candidate | When to consider it | Route to check |
| --- | --- | --- |
| [Exa](https://exa.ai/) | Find and retrieve relevant public web sources | A? / B |
| [Firecrawl](https://www.firecrawl.dev/) | Retrieve or structure authorized public website content | A? / B |
| [Google Trends](https://trends.google.com/trends/) | Compare relative search-interest patterns | B |
| [Google Search Console](https://search.google.com/search-console/about) | Investigate your authorized site's search queries/performance | B / A? |
| [Similarweb](https://www.similarweb.com/) | Directional external market/traffic comparisons | B / A? |
| [Ahrefs](https://ahrefs.com/) | Search demand, content and backlink research | B |
| [Semrush](https://www.semrush.com/) | Competitive search and discoverability research | B / A? |
| [OpenAlex](https://openalex.org/) | Discover scholarly works and citation metadata | A? / B |
| [Crossref](https://www.crossref.org/) | Verify DOI and publication metadata | A? / B |
| [Zotero](https://www.zotero.org/) | Keep a retrievable, source-linked research library | B / F |

Use the [shared routing, capability limits and permissions](../tool-options.md#read-only-what-the-next-decision-needs) before acting.

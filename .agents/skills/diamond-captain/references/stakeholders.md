# Stakeholders and the decision path

Open in Define or Deliver when ownership, conflicting interests or required sign-off can change the task's outcome. Reuse an existing map or a few relevant rows; do not require an organisation-wide exercise.

Completing a stakeholder map does not complete a phase or establish human acceptance.
Tool availability does not establish access or authority to contact, persuade, schedule or message anyone.
A proposed role, planned consultation or reported position is not a verified commitment or observed outcome.

## Map the relevant interests

| Person or role | What they control: budget, sign-off, data, staffing, release | Interest in the current outcome | What they lose or risk from the change | What we need: decision, data, access, capacity | Evidence that would move them | Status: unknown / aligned / neutral / opposed / unreachable | Contact owner |
| --- | --- | --- | --- | --- | --- | --- | --- |
| | | | | | | | |

Include people absorbing work, losing control or carrying new operational risk, not only sponsors and visible users. Link each material stance or commitment to its source/date; leave unsupported positions unknown. Do not infer agreement from silence, or opposition from a job title. Mark proposed owners honestly.

## Trace recommendation to an effective decision

| Step | Actual person or role | Needed artifact or evidence | Required decision / sign-off and its status |
| --- | --- | --- | --- |
| Recommend | | | |
| Decide | | | |
| Consult | | | |
| Inform | | | |

Identify the actual decision owner and necessary sign-offs; use `unassigned` when unknown and record the resulting decision blocker. Continue independent work that does not depend on that missing decision. A role name does not prove authority, an assigned owner does not prove agreement, and a dispatched memo does not prove sign-off.

Choose evidence the deciding stakeholder can act on: operational cost, risk exposure, user harm, measured rate or a binding obligation. State how it could change the decision. This is not permission to distort findings, hide inconvenient results or run a study with a predetermined conclusion; stakeholder agreement is not user evidence.

Record the strongest honest objection and what would make it right. Preserve conflicting interests, rejected recommendations and their reasons rather than flattening them into consensus. Ask the human to resolve consequential trade-offs; do not decide who should bear a loss by default.

## Communicate within authority

A readout, one-page decision memo or policy note is a legitimate Deliver artifact. Make the requested decision, alternatives, rationale, remaining risk, required sign-offs and next owner clear. Label draft, delivered, verified and accepted separately; link the artifact and decision-path record from the existing task journal.

Mapping influence does not authorize outreach. Follow [dialogue versus tool permission](dialogue-and-gates.md#dialogue-versus-tool-permission) before contacting, persuading, scheduling or messaging; prepare the local artifact while that authority is absent.

# Quick overview

**Triple Diamond-inspired · Six stages**

**↗ Diverge — explore broadly · ↘ Converge — focus and choose**

## Diamond 1 — Problem

1. **Discover ↗** — explore users, context and needs.
2. **Define ↘** — choose the problem, goal and success measures.

## Diamond 2 — Solution

3. **Develop ↗** — explore alternatives and create prototypes.
4. **Deliver ↘** — select, refine and implement a solution.

## Diamond 3 — Outcome

5. **Deploy ↗** — gather usage data and feedback after launch.
6. **Digest ↘** — assess impact and decide what to do next.

**Every stage:** Designer goal → input artifacts → optional actions → output artifacts.

**Outputs become the next stage's inputs. Return to any earlier stage when needed.**

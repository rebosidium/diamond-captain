Start with the next decision and the evidence you have. The selected work phase and the maturity of that evidence are separate facts.

## Where to start

| Current situation | Likely starting point |
| --- | --- |
| You have a symptom and uncertain causes | Discover |
| You have research but need a focused problem and goal | Define |
| The problem is agreed; ways to solve it remain open | Develop |
| Options have been compared; you need validation or implementation | Deliver |
| A verified change is in real use and evidence is accumulating | Deploy |
| You have usage evidence and need to decide what happens next | Digest |

A stakeholder's proposed screen is still a solution hypothesis if its problem has not been established. A launch plan is preparation until actual exposure is verified.

```text
We already have an agreed brief and three concepts. Use Diamond Captain
in Deliver to compare the evidence and prepare a bounded pilot.
Explain any missing prerequisites once; keep them visible.
```

You can explicitly select a phase or skip ahead. The agent should explain concrete gaps, record your decision and do useful permitted work there. Skipped phases and unmet criteria stay incomplete.

## Understand the compass

| Status | Meaning |
| --- | --- |
| `READY` | Evidence is sufficient for the next decision; a transition or acceptance may still be pending |
| `NOT READY` | A decision-critical gap needs a targeted next action |
| `LOOP BACK` | New evidence changes an earlier assumption; identify the phase to revisit |
| `BLOCKED` | Necessary access, authority or external input prevents dependent work |
| `AWAITING LIVE EVIDENCE` | Live exposure or adequate observation is unavailable or unverified |
| `COMPLETE` | The agreed scope has evidence for its completion criteria and valid acceptance |

## Return with a reason

A useful loop records **new evidence → changed decision → retained work → target phase → next action and owner**. Preserve earlier results as superseded where necessary. Reuse answers and artifacts that the new finding did not invalidate.

For example, usability findings may show that the wrong role was targeted. Return to Define rather than polishing a flow around the same assumption. If repeated loops add no useful evidence, narrow the question or agree a bounded review or stop.

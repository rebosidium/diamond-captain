# Diamond Captain user guide

Work with your agent to understand a problem, compare solutions and review the result. You choose the direction; the agent uses the evidence and tools available.

## Onboard your agent fast

Copy this into your agent:

```text
Install Diamond Captain for all my projects:
https://github.com/rebosidium/diamond-captain/blob/main/INSTALL-FOR-AGENTS.md
```

Then describe your task. [Install for agents](../../INSTALL-FOR-AGENTS.md) · [Manual installation](../../START-HERE.md) · [Migrating an existing installation](../migration.md)

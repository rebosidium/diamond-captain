# Perplexity Computer compatibility

The [import route](../distributions/perplexity/README.md) reuses the published Diamond Captain Claude Code **0.3.1** archive with complete core **0.4.1**, unchanged. It introduces no separate skill implementation or Perplexity version.

## Preparation and limits

The offline preflight verifies the selected archive digest, public source receipt, every payload hash and the complete tagged core. It preserves archive bytes and prepares a private handoff. This establishes package identity; a successful upload or enabled plugin alone does not establish task execution or durable memory.

Real-client import and execution remain unverified for this package identity. Confirm the account's supported import surface, complete supporting files, explicit activation and actual output before relying on it. Preserve references, templates, scripts and nested tool categories; SKILL.md alone is incomplete.

Use a fresh relevant conversation and verify the actual selected source. Recover an existing task checkpoint without inventing findings, completed checks or acceptance. Respect mandatory host planning/review prerequisites and record the actual sequence. Verify state transfer and recovery between sessions rather than assuming filesystem continuity. Initializer use does not validate later journal edits.

## Keep working records private

Preserve task state separately from the installed package. Keep prompts, responses, screenshots, filled states, runtime paths/identifiers and detailed preparation records outside public source and import ZIPs. Package integrity, skill discovery, model behavior and measured product outcomes are different claims.

# Changelog

## Unreleased

## 0.6.1

- Keep applicable guidance reachable when method/tool catalogs are skipped; link harm/risk review directly from the skill.

## 0.6.0

- Add a conditional product-memory index with evidence freshness, assumptions, task collisions and prediction/outcome calibration; preserve separate task histories and human decisions.
- Add focused guidance for competing tasks, stakeholder losses/sign-off, artifact craft, indirect harm and bounded multi-performer handoffs; preserve the six phases and 60 method IDs.
- Add optional five-line current checkpoints for eligible reversible local tasks, retaining history and explicit upgrade conditions; keep full-state and overwrite protections.
- Add header-only product-memory initialization and regression checks; bound planned actions by review points without weakening mandatory controls.
- Clarify the short context-aware transition after setup; keep source text in English and preserve published packages, hashes and installed copies.

## 0.5.0

- Add optional method menus for all six thinking modes and 60 concise qualitative, quantitative, design and delivery procedures, with selection conditions, outputs and limits. Load only the relevant guidance.
- Finish loading the skill separately, then save intake before opening task files, including file-only requests. Preserve the original checkpoint and append later evidence.
- Keep taskless activation brief and start supplied tasks with useful independent work. Make unsettled problem frames, evidence, unknowns and recommendations inspectable while the human retains product choices and acceptance.
- Preserve task-state format, phase checkpoints, loop history, permission boundaries and existing scoped decisions.
